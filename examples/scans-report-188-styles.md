# Evaluation on real scanned pages

197 scanned pages, whole-page OCR (`--psm 3`, layout analysis included), compared with the proofread page text. Lower is better. 3 more pages were left out because every model scored above 50% CER on them, which almost always means the text belongs to a different page (listed at the end).

- **CER**: character error rate over all text, spaces and punctuation included.
- **Tamil CER**: the same on Tamil characters only. Spacing, punctuation, digits and Latin are ignored, so this isolates how well the Tamil script is read.
- **WER**: word error rate.
- **Words ±**: how many more (or fewer) words the OCR text has than the page. A large plus means words are being split by spurious spaces.
- Running headers and page numbers count when the proofreaders typed them. Curly and straight quotes and the dash variants are treated as the same character; zero-width characters are ignored.
