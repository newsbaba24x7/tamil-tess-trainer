# Fonts for the open model (V2)

233 styles from 71 families, all usable for a published model. "Old letters" is the OpenType feature that draws the pre-1978 letter shapes (default = always). Licence classes: **open** = OFL, GPL, Apache or CC-BY; **free-use** = the author grants free use and distribution, but there is no standard licence.
