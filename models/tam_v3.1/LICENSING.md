# tam v3.1 — licensing and redistribution notes (working document, not legal advice)

Status: published with release v3.1.0 on 2026-11-22. Pull requests to the official repositories are open (see 5).

## 1. What the v3.1 model files contain

| Component | Origin | Licence |
|---|---|---|
| LSTM weights | Fine-tuned from `tam_v3` (tamil-tess-trainer v3.0.0) ← `tam_v2` ← Tesseract `tessdata_best/tam` | Apache-2.0 (same as the base model) |
| Character set (unicharset) | v3 set minus 36 noise entries, plus 8 additions (see `charset_report.md`) | Apache-2.0 |
| Word dictionary (`lstm-word-dawg`, 366,671 words) | v3 dictionary (Tesseract `tam` words + book words from Tamil Wikisource), cleaned to the v3.1 character set | Apache-2.0 for the Tesseract part; Wikisource-derived words: CC BY-SA 4.0 source text, attribution given (see 4). Whether share-alike reaches a word list is unsettled, so it is disclosed |
| Punctuation patterns (404) | v3's 308 patterns with invisible U+200C removed, plus 96 straight single-quote patterns generated by `16_quote_patterns.py` | Apache-2.0 |
| Number patterns (60) | v3 patterns, U+200C removed | Apache-2.0 |
| `config`, `version` | Written for v3.1 | Apache-2.0 |

No font, image or training text is inside the `.traineddata` files.

## 2. Fonts used to render NEW v3.1 training lines (all confirmed from the file or its Debian package)

| Font (styles) | Licence | Evidence |
|---|---|---|
| Noto Sans Tamil (Regular, Bold), Noto Sans Tamil Condensed (Bold) | OFL-1.1 | licence field inside the font file; Debian `fonts-noto-core` copyright |
| Noto Serif Tamil (Regular, Bold), Noto Serif Tamil Slanted (Bold) | OFL-1.1 | same |
| Mukta Malar (ExtraLight, Light, Regular, Medium, SemiBold, Bold, ExtraBold) | OFL-1.1 | licence field inside the font file |
| Lohit Tamil | OFL-1.1 | font file + Debian `fonts-lohit-taml` |
| Lohit Tamil Classical | OFL-1.1 | Debian `fonts-lohit-taml-classical` |
| Samyak Tamil | GPL-3.0-or-later with font exception | Debian `fonts-samyak-taml` |
| Noto Sans, Noto Serif (Latin; Regular, Bold) | OFL-1.1 | font file + Debian `fonts-noto-core` |

Rendering was locked to exactly these files (a private fontconfig), and the renderer recorded the
fonts Pango actually used for every line: none outside this list. `fonts.tsv` also lists the Italic
and Bold Italic files of Noto Sans and Noto Serif; the renderer picks a Latin font with the same slant
as the Tamil font, and no Tamil training font is italic, so these 4 files were never used.

Fonts used only to render EVALUATION lines for v3.1 (not used in v3.1's training, never redistributed):
Noto Sans Tamil Condensed Regular, Noto Serif Tamil Slanted Regular (OFL-1.1); Latha (Microsoft,
proprietary, installed locally); Uni Ila.Sundaram-19/-20 and TAU-Neythal (licences unconfirmed, see 3).
Four of them (Noto Sans Tamil Condensed Regular, Noto Serif Tamil Slanted Regular, Uni Ila.Sundaram-19,
TAU-Neythal; the same files) were used to train tam_v2 and tam_v3, so they are in the v3.1 weights;
only Uni Ila.Sundaram-20 and Latha are new to v3.1. `fonts.json` lists every font used to train or test
each model version (tam_multifont, tam_v2, tam_v3, tam_v3.1).

## 3. Fonts inherited through v3.0 (used to train v3.0, so their influence is in the v3.1 weights)

Research on 2026-11-22. Sources are archived web pages read by a research agent. **Single-source,
not yet independently re-checked**: a second check could not reach web.archive.org.

| Fonts | v3.0 record said | Found | Notes |
|---|---|---|---|
| AkrutiTml1 Normal/Bold | GPL (no version) | GNU GPL, no version stated anywhere found → SPDX `GPL-1.0-or-later` (GPLv2 §9: any version may be chosen) | FSF India announcement; Tamil Linux project README |
| AkrutiTml2 Normal/Bold | GPL (no version) | Same notice, but **withdrawn by FSF India "due to possible copyright issues"**; Debian removed them for the same reason | Recommend: drop from future training; disclose |
| TAMUni-Tamil042/046/150/195, TABUni-Tamil021/032 (Gopi, higopi.com) | GPL | **Not GPL.** Author's page: free use and free redistribution only, "strictly not for sale / commercial re-distribution". The "GPL" label came from a third-party installer | No SPDX id → `LicenseRef-Gopi-TAMUni`. Training use is not addressed |
| TAU-kaviri, -kollidam, -palar, -ponni, -porunai, -pothigai, -thamirabarani (Kadugu / P. S. Ranganathan) | "Free use and distribution" | Source: Sarma's Solutions download page (archived 2007), "TSCII Based Royalty Free Tamil Fonts", thanks to Kadugu; embedded string "[Free Usage/Distribution]". Unicode conversions by Neechalkaran | No SPDX id → `LicenseRef-Kadugu`. Commercial use, modification and training not addressed |
| Uni Ila.Sundaram-01…20 | OFL-1.1 | OFL-1.1 stated only by secondary sources; the author's blog gives no licence | Unconfirmed |
| TAU-Neythal and other TAU fonts (Tamil Virtual Academy) | GPL-2.0+ | TVA policy page: computing resources under GPL-2.0-or-later; fonts not named explicitly | Probable, not explicit |

Font licences govern copying, modifying and redistributing the font software. The model does not
contain or reproduce any font, and OFL/GPL/“free use” terms all permit using the fonts. The risk is
therefore low, but the v3.0 NOTICE is factually wrong for the Gopi and Akruti fonts and should be
corrected. A fully clean lineage would mean retraining from Tesseract's `tam` without the
unconfirmed fonts.

## 5. Redistribution into tesseract-ocr repositories

- The three repos are Apache-2.0 with a single `LICENSE`; v3.1 files are Apache-2.0, so no licence
  file changes are needed. Attribution belongs in the PR description / README, not a new LICENSE.
- Maintainers have redirected community models to `tessdata_contrib` (see the v3.0 review). That
  decision is separate from licensing.
- Pull requests opened 2026-11-22: tesseract-ocr/tessdata_best#89, tesseract-ocr/tessdata#209,
  tesseract-ocr/tessdata_fast#41.
