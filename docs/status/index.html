Making tam_v3.1 Tesseract's Tamil model

Tesseract keeps its official Tamil model, tam, in three repositories: tessdata_best (most accurate), tessdata (integer) and tessdata_fast (smallest and fastest). On 22 November 2026 we opened a pull request in each one to replace tam with the matching tam_v3.1 file. This page explains why that matters and shows where each request stands.

See the status Benchmark results Release v3.1.0

Why merging matters

Tesseract's tam is the Tamil model inside many free OCR programs. Improving it there improves Tamil OCR for all of them at once.

73%

Fewer errors

On 3,968 lines from real scanned Tamil books, tam_v3.1 makes 73% fewer character errors and 67% fewer word errors than the current tam.

0

Extra steps for users

Most people never download a model by hand. They install Tesseract, or a program built on it, and get tam from these repositories. Once merged, tam_v3.1 reaches them with their next update of Tesseract's language files.

3,697 → 0

Invisible characters

The current model writes an invisible character (U+200C) after many pullis, in 3,697 of the 3,968 test lines. tam_v3.1 writes none, so its text searches, copies and sorts correctly.

Apache-2.0

Open, and a drop-in

The same licence, file name and format as the current model, at nearly the same speed, so no program needs to change. Every training and test step is public.

Who it helps

  • Libraries, archives and volunteers digitising old Tamil books, newspapers and records.
  • Blind and low-vision readers, whose screen readers can read a scanned Tamil page only after it becomes text.
  • Students, researchers and everyday users searching and copying text from Tamil documents, in India, Sri Lanka, Singapore, Malaysia and across the world.

What happens next

Tesseract's maintainers are volunteers, and a review can take weeks. If they ask for changes, we will make them and update this page.

You do not have to wait: download tam_v3.1 and read pages with -l tam_v3.1, as shown in the quick start.
