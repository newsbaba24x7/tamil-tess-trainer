tam_v2 is an open Tesseract model for printed Tamil. It was fine-tuned from Tesseract's own Tamil model with openly licensed fonts and 24,445 lines of real scanned books whose text volunteers proofread on Tamil Wikisource. It works with the Tesseract you already have.

Introduction

Tesseract is the most widely used open-source OCR engine, and many free OCR programs read Tamil with its Tamil model, tam. That model has two problems with real books: it misreads many letters in old and worn print, and it writes an invisible character (U+200C) after many pullis, which breaks searching and comparing text.

This project improves Tamil OCR inside Tesseract, so every program that already uses Tesseract can benefit by switching one setting. It has two parts:

  • tam_v2, a ready-to-use model file for Tesseract 5, trained only on data that may be shared;
  • tamtrain, the open tool that trained it: it renders Tamil fonts as scan-like text lines, adds real scanned lines with proofread text, fine-tunes Tesseract's model, and tests models honestly on real pages and public benchmarks.

Every result on this page was measured on text the model never saw in training, and every test can be repeated with the published lists and commands.

Quick start

You need Tesseract 5 (for example sudo apt install tesseract-ocr on Debian or Ubuntu). Download the model and read a page:

curl -LO https://github.com/newsbaba24x7/tamil-tess-trainer/releases/download/v2.0.0/tam_v2.traineddata
tesseract page.png out -l tam_v2 --tessdata-dir .     # writes out.txt
  • Use it everywhere: copy tam_v2.traineddata into Tesseract's tessdata folder (tesseract --list-langs prints where it is). Then -l tam_v2 works without --tessdata-dir, including in programs built on Tesseract.
  • Faster version: tam_v2_fast.traineddata (3.7 MB) is about 28% faster and scores within 0.1 points of the full model.
  • Single text lines: add --psm 13. Whole pages: keep Tesseract's default page mode.
  • Tamil with some English: -l tam_v2+eng (needs Tesseract's English model, eng).
  • Check the download: sha256sum -c SHA256SUMS with the file from the release page.

Features

The tam_v2 model

Trained on real books

24,445 real scanned lines from 37 books, each paired with text that Tamil Wikisource volunteers proofread, plus 186,400 rendered lines in 233 font styles with scan-like damage.

Reads pre-1978 letter shapes

Books printed before the 1978 script reform write ணா றா னா ணை லை ளை னை differently. tam_v2 reads 86.6% of such words exactly (stock: 80.7%) and writes them in modern Unicode.

Clean Unicode text

No invisible U+200C after pullis, composed vowel signs (ொ ோ ௌ) and NFC normalisation, so the text searches and sorts correctly.

Fewer stray digits

Damaged letters are no longer read as Tamil digits (௬ for சு): 11 stray digits on the 197 test pages, against 173 for the stock model.

Book vocabulary

Its dictionary adds 41,431 words from proofread books to Tesseract's own Tamil word list.

Drop-in for Tesseract 5

One .traineddata file, in a full (float) and a fast (integer) version. Same command line, same API, no other software.

The tamtrain tool

Fonts to training lines

Renders thousands of scan-like lines per font, with ink spread, fading, show-through, blur and warped baselines. Checks every font first: legacy encodings, missing letters, broken shaping, old letter shapes.

Real lines from proofread books

Matches proofread Wikisource pages with archive.org scans, cuts them into lines and keeps only lines whose boundaries agree with the text.

Honest evaluation

Tests on real scanned pages and any line benchmark, with CER, WER, BLEU, ANLS and METEOR, results by page difficulty and the most common confusions.

Reproducible

Seeded rendering, saved settings, published page and line lists, and a licence record for every font. The training lines can be rebuilt pixel for pixel.

What the models taught us: V1 learned its fonts very well (rendered-line CER 6.54% → 2.01%) but did not improve real scans at all. V2-research fixed old letter shapes, word spacing and stray digits and beat the stock model on real pages. tam_v2 added real scanned lines and moved to openly licensed fonts only.

How it was built

  1. Collect fonts and check their licencesAbout 95 Tamil font families were collected and tested. tam_v2 uses 233 styles from 71 families with open licences (OFL, GPL, Apache, CC-BY) or free-use terms; 64 of them can draw the pre-1978 letter shapes.
  2. Render scan-like lines186,400 lines with book-style text from proofread Wikisource books, with realistic word spacing and scan damage. Three font families are held out for testing.
  3. Cut real scans into linesFully proofread Wikisource books were matched with their scans on archive.org, often 600 ppi copies from the Tamil Virtual Academy. Lines are kept only when their first and last words agree with the proofread text. No test book is used.
  4. Fine-tune Tesseract's modelStarting from tessdata_best tam: 100,000 iterations on rendered and real lines (real lines shown three times), checked on 2,854 real lines from five other books. About 4 hours on 4 CPU cores.
  5. Test on what it never saw197 real pages, their 3,968 lines, the RANLP 2025 set, the Tamil OCR Benchmark and the scanning-resolution sets, against the stock model and the earlier models.

Limitations

  • Spurious spaces. On clean pages 12.6% of words are still wrong. The largest cause is a space that splits a word, mostly right after a vowel sign or pulli (தரை யோடு), then wrong letters, punctuation and page headers.
  • English words inside Tamil lines are often misread.
  • Hard pages stay hard: tables, several columns and badly damaged print (18.1% CER).
  • Low resolution: at 72–96 DPI errors roughly triple; scan at 300 DPI.
  • Not tested yet: old and contemporary newspapers.
  • Not for handwriting, or for PDFs whose text layer uses legacy encodings (TSCII, TAB/TAM, Bamini).

Train your own

tamtrain needs Tesseract 5 with its training tools and Python 3.9+ with Pillow built with libraqm. Point it at a folder of Unicode Tamil fonts:

git clone https://github.com/newsbaba24x7/tamil-tess-trainer
cd tamil-tess-trainer
python3 -m tamtrain fonts --fonts ~/my-tamil-fonts --ocr-check     # which fonts can be used
python3 -m tamtrain all --fonts ~/my-tamil-fonts --name tam_myfonts \
    --lines-per-font 1000 --iterations 10000                       # render, train, evaluate
python3 -m tamtrain scans my-scans/ --work work                    # test on your own scanned pages

The README covers every option, the real-line pipeline, and how to rebuild tam_v2's exact training lines from the published line list.

FAQ

Do I need anything besides Tesseract?
No. tam_v2 is a model file for Tesseract 5. Download it and use -l tam_v2.
Can I use it commercially?
Yes, tam_v2 is Apache-2.0. The V2-research model is for non-commercial use only, because some of its training fonts are.
Does it send my documents anywhere?
No. Tesseract runs entirely on your computer.
Will it read old books?
Yes, including the pre-1978 letter shapes, which it outputs as modern Unicode. Scan at 300 DPI for the best results.
Why is word accuracy lower than character accuracy?
Tamil words in these books average about 8 characters, so one wrong letter or one wrong space anywhere makes the whole word wrong.
How can I help?
Report misread pages in GitHub issues, proofread pages on Tamil Wikisource (every proofread page can become training data), or suggest openly licensed fonts.
