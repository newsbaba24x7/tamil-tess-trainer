Tamil OCR for Tesseract தமிழ் எழுத்துணரி

tam_v3.1 is a set of three open Tesseract models for printed Tamil, one for each kind of official Tesseract model: best (float), integer and fast. They build on tam_v3, which was trained on 174,624 lines from 394 real scanned books and periodicals whose text volunteers proofread on Tamil Wikisource. They work with the Tesseract you already have.

Introduction

Tesseract is the most widely used open-source OCR engine, and many free OCR programs read Tamil with its Tamil model, tam. That model has two problems with real books: it misreads many letters in old and worn print, and it writes an invisible character (U+200C) after many pullis, which breaks searching and comparing text.

This project improves Tamil OCR inside Tesseract, so every program that already uses Tesseract can benefit by switching one setting. It has two parts:

  • tam_v3.1, ready-to-use model files for Tesseract 5 (best, integer and fast), fine-tuned from tam_v3;
  • tamtrain, the open tool that trained tam_v2 and tam_v3: it renders Tamil fonts as scan-like text lines, adds real scanned lines with proofread text, fine-tunes Tesseract's model, and tests models honestly on real pages and public benchmarks.

Every result on this page was measured on text the model never saw in training, and every test can be repeated with the published lists and commands.

Quick start

You need Tesseract 5 (for example sudo apt install tesseract-ocr on Debian or Ubuntu). Download the model and read a page:

curl -LO https://github.com/newsbaba24x7/tamil-tess-trainer/releases/download/v3.1.0/tam_v3.1.traineddata
tesseract page.png out -l tam_v3.1 --tessdata-dir .     # writes out.txt
  • Use it everywhere: copy tam_v3.1.traineddata into Tesseract's tessdata folder (tesseract --list-langs prints where it is). Then -l tam_v3.1 works without --tessdata-dir, including in programs built on Tesseract. Saved as tam.traineddata, it replaces Tesseract's Tamil model.
  • Other versions: tam_best_v3.1 (7.3 MB, float) is the most accurate and the one to fine-tune; tam_fast_v3.1 (4.4 MB) is the smallest network and the best of the three on Tamil numerals and English words.
  • Single text lines: add --psm 13. Whole pages: keep Tesseract's default page mode.
  • Tamil with some English: -l tam_v3.1 alone; it reads Latin letters.
  • Check the download: sha256sum -c SHA256SUMS with the file from the release page.

Features

The tam_v3.1 models

Trained on real books

tam_v3 learned from 174,624 real scanned lines from 394 books and periodical issues, from 1847 to today, each paired with text that Tamil Wikisource volunteers proofread. tam_v3.1 trains again on 16,012 of them, mixed with new rendered lines.

Reads pre-1978 letter shapes

Books printed before the 1978 script reform write ணா றா னா ணை லை ளை னை differently. tam_v3, on which tam_v3.1 builds, reads 87.8% of such words exactly (stock: 80.7%) and writes them in modern Unicode.

Clean Unicode text

No invisible U+200C after pullis, composed vowel signs (ொ ோ ௌ) and NFC normalisation, so the text searches and sorts correctly.

English words and numerals

tam_v3.1 adds English words, technical terms and all 36 Tamil numeral forms to training. On rendered mixed Tamil-English lines, tam_fast_v3.1 makes 40% fewer character errors than tam_v3.

Book vocabulary

Its dictionary of 366,671 words combines the vocabulary of 420 proofread books with Tesseract's own Tamil word list, and its punctuation patterns know straight quotes.

Drop-in for Tesseract 5

Three .traineddata files in the formats of Tesseract's own repositories: best (float), integer and fast. Same command line, same API, no other software.

The tamtrain tool

Fonts to training lines

Renders thousands of scan-like lines per font, with ink spread, fading, show-through, blur and warped baselines. Checks every font first: legacy encodings, missing letters, broken shaping, old letter shapes.

Real lines from proofread books

Finds books with enough proofread pages, gets their scans from archive.org or Wikimedia, cuts them into lines and keeps only lines whose boundaries agree with the text.

Honest evaluation

Tests on real scanned pages and any line benchmark, with CER, WER, BLEU, ANLS and METEOR, results by page difficulty and the most common confusions.

Reproducible

Seeded rendering, saved settings, published page and line lists, and a licence record for every font. The training lines can be rebuilt pixel for pixel.

What the models taught us: V1 learned its fonts very well (rendered-line CER 6.54% → 2.01%) but did not improve real scans at all. V2-research fixed old letter shapes, word spacing and stray digits and beat the stock model on real pages. tam_v2 added real scanned lines and moved to openly licensed fonts only. tam_v3 added seven times as many real lines, from 394 books and periodicals, and Wikipedia text with English names. tam_v3.1 cleaned the character set, added numerals, English words and punctuation, and made files for all three of Tesseract's model repositories.

How it was built

  1. Collect fonts and check their licencesAbout 95 Tamil font families were collected and tested. tam_v2 and tam_v3 use 233 styles from 71 families with open licences (OFL, GPL, Apache, CC-BY) or free-use terms; 64 of them can draw the pre-1978 letter shapes.
  2. Render scan-like linesBook text from 420 proofread Wikisource books, Tesseract's own training text and Tamil Wikipedia sentences, drawn with realistic word spacing and scan damage. Three font families are held out for testing.
  3. Cut real scans into linesBooks with enough proofread pages on Tamil Wikisource were matched with their scans on archive.org (often 600 ppi copies from the Tamil Virtual Academy) or rendered from Wikimedia's copy. Lines are kept only when their first and last words agree with the proofread text. No test book is used, and lines that share text with any test set are dropped.
  4. Fine-tune Tesseract's modeltam_v2 was trained from tessdata_best tam for 100,000 iterations; tam_v3 continued from tam_v2 for 270,000 iterations on 174,624 real and 91,530 rendered lines, in sessions of 20,000, checked on 2,854 real lines from five other books. About 4.5 hours on 2 CPU threads.
  5. tam_v3.1tam_v3 was trained again for 20,000 iterations on 16,012 of its real lines mixed half and half with rendered lines that add Tamil numerals, English words and book punctuation, then blended with tam_v3 (0.5 each). The integer and fast versions were made from that model. Scripts: models/tam_v3.1.
  6. Test on what it never saw197 real pages, their 3,968 lines, the RANLP 2025 set, the Tamil OCR Benchmark and the scanning-resolution sets, against the stock model, the earlier models and a third-party model; then handwriting and camera photos of documents.

Limitations

  • Word errors: 6.9% of words on the real test lines are still wrong with tam_best_v3.1, mostly from punctuation and spacing.
  • Tamil numerals: tam_best_v3.1 and tam_v3.1 read 57% of the numerals on rendered lines (stock: 82%, tam_fast_v3.1: 80%); Tamil digits look like letters. The symbols ௳–௺ ௐ are not read by them.
  • Not yet measured for tam_v3.1: whole pages, low-resolution scans, newspapers, handwriting and photos. tam_v3's limits there probably still apply: spurious spaces that split words, errors that rise steeply below 150 DPI (scan at 200 DPI or more), hard pages with tables or damaged print, and handwriting (45% CER). See the tam_v3 benchmark page.
  • Covers and posters: Tesseract's default page mode often skips large or decorated titles; try --psm 11 (sparse text).
  • Single-line modes with Tesseract 5.5.0–5.5.3: the command-line program can stop with "Floating point exception" on rare lines (tam_fast_v3.1: 2 of 8,211 test lines with --psm 7). This Tesseract bug is fixed in 5.5.4.
  • Not for PDFs whose text layer uses legacy encodings (TSCII, TAB/TAM, Bamini).

Train your own

tamtrain needs Tesseract 5 with its training tools and Python 3.9+ with Pillow built with libraqm. Point it at a folder of Unicode Tamil fonts:

git clone https://github.com/newsbaba24x7/tamil-tess-trainer
cd tamil-tess-trainer
python3 -m tamtrain fonts --fonts ~/my-tamil-fonts --ocr-check     # which fonts can be used
python3 -m tamtrain all --fonts ~/my-tamil-fonts --name tam_myfonts \
    --lines-per-font 1000 --iterations 10000                       # render, train, evaluate
python3 -m tamtrain scans my-scans/ --work work                    # test on your own scanned pages

The README covers every option, the real-line pipeline, and how to rebuild tam_v3's exact training lines from the published line list. tam_v3.1's scripts are in models/tam_v3.1.

FAQ

Do I need anything besides Tesseract?
No. tam_v3.1 is a model file for Tesseract 5. Download it and use -l tam_v3.1.
Can I use it commercially?
Yes, tam_v3.1 (like tam_v3 and tam_v2) is Apache-2.0. The V2-research model is for non-commercial use only, because some of its training fonts are.
Does it send my documents anywhere?
No. Tesseract runs entirely on your computer.
Will it read old books?
Yes, including the pre-1978 letter shapes, which it outputs as modern Unicode. Scan at 200 DPI or more for the best results.
Why is word accuracy lower than character accuracy?
Tamil words in these books average about 8 characters, so one wrong letter or one wrong space anywhere makes the whole word wrong.
How can I help?
Report misread pages in GitHub issues, proofread pages on Tamil Wikisource (every proofread page can become training data), or suggest openly licensed fonts.
